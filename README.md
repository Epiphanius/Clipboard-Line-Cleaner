# Clipboard Line Cleaner
Automatically removes empty lines and beginning spaces from clipboard text. It is available as a GNOME Shell extension (versions 45+). The latest version, 5, can be found here: https://extensions.gnome.org/extension/10084/clipboard-line-cleaner/. An unreviewed version 6 (clipboard-line-cleaner@epiphanius.github.io-03.10.2026.zip) can be found above. The extension now has the option to transform text into continuous text. Hyphenations at the end of a line are removed and words are rejoined. Auto-cleaning is skipped if clipboard text exceeds 1 MB, for example, to prevent the GNOME Shell thread from freezing.
At first glance, the tool may seem rather nonsensical, but it arose from my desire to avoid having to rework the layout of text copies manually. I am considering adding  two input fields for search and replace and output options, but I should first identify a need for these features. Help is welcome!
